# Paradise Nursery

Paradise Nursery is an online plant shop built with React.

## Project Description
This project allows customers to explore a variety of
houseplants, add plants to their shopping cart,
update quantities, and view the total price.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit

## Features
- Landing Page
- About Us Section
- Plant Product Listing
- Shopping Cart
- Add and Remove Items
- Update Product Quantities
